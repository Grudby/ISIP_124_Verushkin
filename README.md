# ISIP_124_Verushkin

Практические работы по C#. Выполнил: **Верушкин Василий Андреевич**, группа **ИСиП-124**.

Каждая практическая работа находится в отдельной ветке:

| Ветка | Практическая работа | Проект |
|---|---|---|
| `pr1` | Учёт потраченных за день средств | `Pr1_Expenses` |
| `pr2` | Учёт товаров в магазине | `Pr2_StoreInventory` |
| `pr3` | Анализ текста (без LINQ) | `Pr3_TextAnalyzer` |
| `pr4` | Учёт книг в библиотеке (LINQ) | `Pr4_Library` |
| `pr5` | Система управления университетом (ООП) | `Pr5_University` |
| `pr6` | Текстовый рогалик | `Pr6_Roguelike` |
| `pr7` | Маркетплейс с БД на EF Core | `Pr7_Marketplace` |

## Практическая работа 1 - учёт трат

- ввод количества операций (от 2 до 40);
- ввод трат в формате `Название; Сумма`;
- меню: вывод данных, статистика (сумма, среднее, максимум, минимум),
  пузырьковая сортировка по цене, конвертация валюты, поиск по названию.

## Запуск

Нужен .NET 8 SDK. Открыть `ISIP_124_Verushkin.sln` в Visual Studio или выполнить:

```
dotnet run --project Pr1_Expenses
```
