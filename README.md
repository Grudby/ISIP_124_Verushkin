# Практическая работа 6 - текстовый рогалик

Выполнил: **Верушкин Василий Андреевич**, группа **ИСиП-124**.

Пошаговая консольная игра. На каждом ходу с шансом 50 на 50 игрок находит сундук или встречает
случайного врага, каждый 10-й ход - случайный босс.

- игрок: здоровье, одно оружие и один доспех;
- враги: Гоблин (шанс крита), Скелет (игнорирует защиту), Маг (шанс заморозки - пропуск хода);
- боссы: ВВГ (Гоблин), Ковальский (Скелет), Архимаг C++ (Маг), Пестов С-- (Скелет с заморозкой)
  с множителями характеристик из задания;
- бой: игрок ходит первым, выбирает атаку или защиту; защита даёт 40% шанс уклониться,
  иначе срабатывает блок на 70-100% от защиты; затем враг атакует со своими особенностями;
- сундук: лечебное зелье (полное лечение), оружие или доспех с выбором - взять или выбросить;
- все шансы и случайные величины определяются генератором случайных чисел (`Rng`).

ООП: абстрактные классы `Item`, `Equipment`, `Enemy`; особенности врагов задаются переопределением
свойств `CritChance`, `FreezeChance`, `IgnoresDefense`; боссы наследуются от своей расы.

Дополнительное задание:

- редкость предметов: обычный 60%, редкий 25%, эпический 12%, легендарный 3%;
- сохранение и загрузка прогресса в файл `save.json`.

## Запуск

Нужен .NET 8 SDK. Открыть `ISIP_124_Verushkin.sln` в Visual Studio или выполнить:

```
dotnet run --project Pr6_Roguelike
```
