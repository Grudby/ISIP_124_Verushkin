# Практическая работа 4 - учёт книг в библиотеке

Выполнил: **Верушкин Василий Андреевич**, группа **ИСиП-124**.

Фильтрация, сортировка и группировка выполнены через LINQ.

- книга: ID (назначается автоматически), название, автор, жанр (5 вариантов), год издания, цена;
- пять тестовых книг при запуске;
- добавление книги с проверкой всех значений и удаление по ID;
- поиск по названию, автору и жанру;
- сортировка по названию и по году издания;
- самая дорогая и самая дешёвая книга;
- количество книг каждого автора.

Дополнительное задание:

- пакетный импорт строк в формате `Название;Автор;Жанр;Год;Цена`
  (некорректные строки пропускаются с указанием причины);
- корзина: добавление книг с количеством, удаление, итоговая стоимость и оформление покупки.

## Запуск

Нужен .NET 8 SDK. Открыть `ISIP_124_Verushkin.sln` в Visual Studio или выполнить:

```
dotnet run --project Pr4_Library
```
