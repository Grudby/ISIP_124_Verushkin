# Практическая работа 5 - система управления университетом

Выполнил: **Верушкин Василий Андреевич**, группа **ИСиП-124**.

Консольная система для работы со студентами, преподавателями и курсами.

- студенты: добавление, список, информация, запись на курс, курсы студента;
- преподаватели: добавление, список, информация, назначение на курс;
- курсы: создание, список, информация о курсе и список его студентов;
- вывод всех участников учебного процесса;
- проверка всех вводимых значений (ФИО, возраст, email, телефон, стаж, часы курса).

Принципы ООП:

- **абстракция** - абстрактный класс `Person` с общими данными и абстрактным свойством `Role`;
- **наследование** - `Student` и `Teacher` наследуются от `Person`;
- **инкапсуляция** - поля закрыты, значения проверяются в свойствах, списки курсов и студентов
  доступны только для чтения и меняются через методы `Course.Enroll` и `Course.AssignTeacher`;
- **полиморфизм** - переопределённый `GetInfo()` у каждого типа, общий список участников
  выводится через базовый класс `Person`.

## Запуск

Нужен .NET 8 SDK. Открыть `ISIP_124_Verushkin.sln` в Visual Studio или выполнить:

```
dotnet run --project Pr5_University
```
