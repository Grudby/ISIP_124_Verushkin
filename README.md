# Практическая работа 3 - анализ текста

Выполнил: **Верушкин Василий Андреевич**, группа **ИСиП-124**.

Выполнена без использования LINQ.

- ввод текста не короче 100 символов (ввод завершается пустой строкой);
- количество слов, самое короткое и самое длинное слово;
- количество предложений, гласных и согласных букв;
- частота встречаемости каждой буквы;
- работа с новым текстом, сохранение статистики в список и вывод статистики по прошлым текстам.

## Запуск

Нужен .NET 8 SDK. Открыть `ISIP_124_Verushkin.sln` в Visual Studio или выполнить:

```
dotnet run --project Pr3_TextAnalyzer
```
