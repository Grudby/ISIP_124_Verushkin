# Практическая работа 2 - учёт товаров в магазине

Выполнил: **Верушкин Василий Андреевич**, группа **ИСиП-124**.

- товар: код, название, цена, количество, наличие, категория;
- добавление, удаление, заказ поставки и продажа товара;
- поиск по коду, названию и категории;
- отмена последней продажи (стек истории продаж) и отчёт о продажах.

## Запуск

Нужен .NET 8 SDK. Открыть `ISIP_124_Verushkin.sln` в Visual Studio или выполнить:

```
dotnet run --project Pr2_StoreInventory
```
