# Практическая работа 7 - маркетплейс GMWOG||GG.MOW||WONGG

Выполнил: **Верушкин Василий Андреевич**, группа **ИСиП-124**.

Консольный онлайн-маркетплейс с базой данных на EF Core (SQLite).

- просмотр каталога товаров доступен без входа;
- регистрация (ник и пароль с повторным вводом), вход в существующий аккаунт и выход;
- пароль хранится только в виде хеша PBKDF2 с солью;
- корзина: добавление товара с проверкой остатка, просмотр с итоговой суммой, удаление позиции;
- покупка одного товара из корзины или всей корзины сразу с выбором пункта выдачи заказов;
- история заказов с сортировкой по дате (сначала новые или сначала старые).

## База данных

Файл `MarketplaceDatabase.db` создаётся автоматически при первом запуске рядом с программой
и заполняется категориями, товарами и пунктами выдачи. Структура приведена к 3НФ:

| Таблица | Столбцы |
|---|---|
| `User` | `Id`, `Login` (уникальный), `PasswordHash`, `PasswordSalt`, `CreatedAt` |
| `Category` | `Id`, `Name` (уникальное) |
| `Product` | `Id`, `Name`, `Description`, `Price`, `StockQuantity`, `CategoryId` |
| `CartItem` | `Id`, `UserId`, `ProductId`, `Quantity` (пара `UserId` + `ProductId` уникальна) |
| `PickupPoint` | `Id`, `Address`, `WorkingHours` |
| `Order` | `Id`, `UserId`, `PickupPointId`, `CreatedAt` |
| `OrderProduct` | `Id`, `OrderId`, `ProductId`, `Quantity`, `Price` |

`OrderProduct.Price` - цена на момент покупки, чтобы история заказов не менялась при изменении цены товара.
Сумма заказа не хранится, а считается по позициям.

## Запуск

Нужен .NET 8 SDK. Открыть `ISIP_124_Verushkin.sln` в Visual Studio или выполнить:

```
dotnet run --project Pr7_Marketplace
```
